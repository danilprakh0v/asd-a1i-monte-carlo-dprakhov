# Исследование метода Монте-Карло для вычисления площади

Этот репозиторий содержит материалы для ДЗ А1i по курсу "Алгоритмы и структуры данных". 
Цель работы — практически исследовать эффективность метода Монте-Карло для нахождения площади фигуры, образованной пересечением трех кругов.

Работа состоит из двух основных частей:
1.  **Экспериментальный анализ:** Сравнение точности и скорости сходимости метода в зависимости от выбора "широкой" и "узкой" ограничивающих областей, а также кол-ва генерируемых точек.
2.  **Решение для Codeforces:** Оптимизированная версия алгоритма для сдачи в систему программирования.

## Структура репозитория

*   `monte-carlo-sq.cpp`: Скрипт на C++ для проведения эксперимента. Он запускает симуляции с разным количеством точек ($N$) и выводит результаты в CSV-формате.
*   `monte-carlo-cf.cpp`: Решение задачи A1i для системы Codeforces. Принимает на вход параметры трех кругов и выводит одно число — вычисленную площадь.
*   `monte-carlo-trial-data.csv`: Данные, полученные в результате работы скрипта `monte-carlo-sq.cpp`.
*   `Monte-Carlo-GraphPlot.ipynb`: Jupyter Notebook (совместимый с Google Colab) для визуализации данных из `monte-carlo-trial-data.csv`.
*   `Conversion-Graph.png`: Итоговый график, показывающий сходимость приближенного значения площади к точному.
*   `Error-Graph.png`: Итоговый график, показывающий зависимость относительной погрешности от количества точек $N$.

## Как воспроизвести результаты

### Часть 1: Экспериментальный анализ и построение графиков

#### Шаг 1: Генерация данных

1.  Скомпилируйте скрипт для эксперимента с помощью компилятора g++:
    ```bash
    g++ monte-carlo-sq.cpp -o experiment -std=c++17
    ```
2.  Запустите скомпилированную программу, перенаправив ее вывод в CSV-файл:
    ```bash
    ./experiment > monte-carlo-trial-data.csv
    ```
    После выполнения этой команды в папке появится свежий файл `monte-carlo-trial-data.csv`.

#### Шаг 2: Визуализация

1.  Откройте `Monte-Carlo-GraphPlot.ipynb` в среде Jupyter Notebook или загрузите его в Google Colabor.
2.  **Если вы используете Google Colab**, не забудьте загрузить файл `monte-carlo-trial-data.csv` в сессионное хранилище.
3.  Запустите все ячейки блокнота. Скрипт автоматически прочитает данные и построит графики, аналогичные `Conversion-Graph.png` и `Error-Graph.png`.

### Часть 2: Решение для Codeforces

1.  Скомпилируйте версию для Codeforces:
    ```bash
    g++ monte-carlo-cf.cpp -o solution -std=c++17
    ```
2.  Для проверки создайте файл `input.txt` с входными данными, например:
    ```
    0.0 0.0 1.0
    1.0 1.0 1.0
    0.0 1.0 1.0
    ```
3.  Запустите решение, передав ему данные из файла:
    ```bash
    ./solution < input.txt
    ```
    Программа выведет в консоль одно число — приближенную оценку площади.

## Используемые технологии

*   **C++ (стандарт C++17):** для высокопроизводительных вычислений.
*   **Python 3:** для анализа и визуализации данных.
*   **Библиотеки Python:** Pandas, Matplotlib.
